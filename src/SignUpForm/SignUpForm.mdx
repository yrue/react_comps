### SignUpForm

#### Overview

## Features
1. Input fields with validation: username, email, password, and confirm password.
2. Handle form submission when the submit button is clicked.

## Details
- State management - what to render? input valid, error message. what to store? form fields data, including key, value, errors. when to update value and errors? when input change, update value and errors by field key.
- controlled or uncontrolled input? use controlled input
- Validation timing: onSubmit, via API, ✅ onChange (with debounce? ❌) for smoother UX.
- Inline validation error messages.
- Accessibility: 
  - Input fields with `aria-describedby`.

### Improvements
- Disable the submit button while waiting for the API response.
- Enable the submit button only when all fields are valid.
- Refactor the fields into smaller components for easier customization, such as styling.
