### Overview
A simple to-do list.

### Features
- Add tasks with the "Submit" button.
- Clear input after task is added.
- Delete tasks using the "Delete" button.

### Details
> 💡 Use `key` for list, ensure input accessibility, choose data structure for tasks

- **State to maintain**: 
  - `tasks`: List of tasks with unique IDs and titles.
  - `newTask`: New task title (string).
- **Data structure for tasks**: 
  - ✅ Use `Map` for better performance (lookup, insert, delete).
- Render tasks with unique IDs as keys in JSX.
- Add tasks with a generated ID after clicking submit.
- Remove tasks by ID when clicking delete.
- **Accessibility**: Use label for input (`aria-label` or `<label>`).

### Possible Improvements
- Disable the submit button if input is empty.
- Handle input truncation.
