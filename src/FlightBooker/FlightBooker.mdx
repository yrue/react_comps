# FlightBooker
> 💡 form, select, date input(`min` attribute), vitest

A component that enables booking flights, offering both one-way and return options for specified dates.

{/* Overview */}

## Features

- **Flight Options:**  
  Choose between one-way and return flights (default is return).

- **Input Fields:**  
  Includes an input field with the following details:

  <table>
    <thead>
      <tr>
        <th>option\input</th>
        <th>departure</th>
        <th>return</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>one-way</td>
        <td>✅</td>
        <td>❌</td>
      </tr>
      <tr>
        <td>return</td>
        <td>✅</td>
        <td>✅</td>
      </tr>
    </tbody>
  </table>

- **Validation Rules:**  
  The input is considered invalid if:
  - A past date is selected.
  - The return date is earlier than the departure date.

- **Submission:**  
  Displays the booked flight details after the form is submitted.

## Details

- **Data Structure:**
  - **Option:** `one-way` or `return` (default: return)
  - **Date:**
    - For one-way: a single date.
    - For return: a pair of dates.
  - **Valid:** A boolean flag indicating validity.
  - **Booked Flight:** Initially empty (`''`), then updated with the selected date or dates.

- **Handling Option Switching:** ⚠️ Use simple one as the UX is not smooth with the complex one.
  - **Simple Approach:** Hide or Show the arrive date when switching between flight options.
  - ✅ **Complex Approach:** Retain the previous state when switching options. 

- **State Management:**
  - **option:** Managed as an auto-enumerated value.
  - **dateObj:** An object structured as `{ oneWay: [date], return: [date, date] }`.

- **Validation:**  
  Options: ✅onChange, onSubmit
  Validate the selected date(s) and compute an inner date variable for performance optimization (using memoization) to avoid unnecessary re-renders.

- **User Interface:**
  - **Form Elements:**
    - Flight option selector.
    - Date input field(s).
    - Error messages (displayed in a `<p>` element).
  - **Submit Button:** For form submission.
  - **Booked Message:** Displayed in a `<p>` element after booking.
